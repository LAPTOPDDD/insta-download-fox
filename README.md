# Insta Download Fox

Браузерное расширение для скачивания видео, Reels и каруселей с Instagram одним нажатием.

## Возможности

- Кнопка **⬇ DL** прямо на посте/Reels в ленте
- Кнопка «Скачать с видимого поста» в popup-окне расширения
- Скачивание всех элементов карусели одним нажатием
- Перехват медиа через injected-сниффер (`sniffer.js`)
- Сохранение файлов в папку `Изображения/InstaFox/<код поста>`
- Тосты-уведомления о статусе скачивания

## Установка

### Firefox

1. Откройте `about:debugging#/runtime/this-firefox`
2. Нажмите **Загрузить временное дополнение…**
3. Выберите файл `manifest.json` из этой папки

### Chrome / Chromium

1. Откройте `chrome://extensions`
2. Включите **Режим разработчика**
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку

## Использование

1. Откройте пост, Reels или карусель на instagram.com
2. Нажмите **⬇ DL** на посте или кнопку в popup расширения
3. Файлы сохранятся в папку `Изображения/InstaFox/<код поста>`

## Технические детали

- Manifest V2, gecko id: `insta-download-fox@local` (Firefox >= 91)
- Разрешения: `downloads`, `activeTab`, `storage`, `*://*.instagram.com/*`
- Content script внедряется на `document_start`, сниффер — как web accessible resource

## Файлы

| Файл | Назначение |
|---|---|
| `manifest.json` | Манифест расширения |
| `content.js` / `content.css` | Кнопки и UI на страницах Instagram |
| `sniffer.js` | Перехват медиа-URL на странице |
| `background.js` | Скачивание файлов через `chrome.downloads` |
| `popup.html` / `popup.js` | Popup-интерфейс |

## Лицензия

Свободное использование без гарантий.
